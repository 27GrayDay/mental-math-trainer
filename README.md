# Тренажёр устного счёта

Бесплатный тренажёр устного счёта для школьников и репетиторов. Работает в браузере на телефоне и компьютере,
устанавливается на домашний экран как приложение (PWA) и не требует регистрации.

**Открытый исходный код.** Проект распространяется по лицензии [MIT](LICENSE): его можно бесплатно использовать,
изменять и распространять, в том числе в учебных и коммерческих целях. Предложения и исправления приветствуются
через Issues и Pull Requests.

> Проект независимый: он не связан с сервисом «Образавр» и не использует его код, тексты или оформление.

## Возможности
- Действия: сложение, вычитание, умножение, деление, степени и корни. У каждого действия своё меню вариантов
  (диапазоны, таблицы, «на 7», «до 400» и т. д.), можно комбинировать несколько действий.
- Примеры из двух или трёх чисел, режим с отрицательными числами.
- Примеры не повторяются, нет бессмысленных вариантов (деление с остатком, `a × b ÷ b` и т. п.).
- Таймер тренировки и ограничение времени на вопрос. После ошибки время на вопрос стоит, пока ученик не введёт
  верный ответ.
- История решённых примеров, очки и множитель за серию верных ответов, рекорд, итоговый разбор ошибок.
- Экранная клавиатура, звук, полноэкранный режим, светлая и тёмная темы.

## Звуки
Положите свои файлы `correct.wav` (верный ответ) и `wrong.mp3` (ошибка) в папку `public/sounds/`.
Если файлов нет, тренажёр играет простые сигналы.

## Режим «ОГЭ № 19»
Тренировка по заданию 19 ОГЭ (геометрия): ученику показывают **одно утверждение**, он выбирает «Верно» или «Неверно»,
после ответа видит **разбор**. Так утверждения запоминаются по одному, а не угадываются из трёх вариантов.

- Утверждения с ошибкой возвращаются через 3–5 шагов, пока ученик не ответит верно.
- Прогресс хранится в браузере: утверждение считается выученным после трёх верных ответов подряд в разных тренировках.
  Выученные можно скрывать («Только невыученные»).
- Режимы переключаются сегментным контролом сверху страницы.

### Как добавить утверждения и чертежи
Все утверждения лежат в `src/oge19/data/statements.ts`. Чтобы добавить своё, допишите объект в конец массива:
```ts
{ id: 's122', text: 'Текст утверждения.', answer: true, explanation: 'Почему верно или неверно.', figure: 's122.svg' }
```
`id` должен быть уникальным и не меняться (по нему хранится прогресс). Чертёж необязателен: положите файл
в `public/figures/` и укажите его имя в поле `figure`.

## Стек
React 18, TypeScript, Vite, MUI (Material UI), PWA (vite-plugin-pwa).

## Запуск
```bash
npm install
npm run dev      # режим разработки
npm run build    # production-сборка в dist/
npm run preview  # локальный просмотр сборки
```

## Публикация на GitHub Pages
1. Создайте **публичный** репозиторий на GitHub и отправьте в него код в ветку `main`.
2. Откройте Settings → Pages и в поле Source выберите **GitHub Actions**.
3. Сайт соберётся и опубликуется автоматически (`.github/workflows/deploy.yml`).
   Адрес: `https://<ваш-логин>.github.io/<имя-репозитория>/`.

После каждого `git push` в `main` сайт обновляется сам.

## Структура
```
src/
  types.ts, constants.ts, theme.ts   типы, меню и настройки по умолчанию, тема в стиле iOS
  domain/                            генерация примеров (чистая логика, без React)
  engine/TrainerEngine.ts            правила тренировки: очки, множитель, таймеры, ошибки
  services/                          localStorage и звук
  hooks/                             useTrainer, useSettings, useHotkeys
  components/                        интерфейс: QuestionBoard, Keypad, Stats, settings/*, ui/*
  screens/CalcScreen.tsx             режим «Устный счёт»
  oge19/                             режим «ОГЭ № 19»: данные, движок, компоненты
  App.tsx                            оболочка: переключатель режимов
```
